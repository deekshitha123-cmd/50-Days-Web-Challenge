# 🚀 Day 12 – State Manipulation & Dynamic Menus (Mobile Navigation)

## 📖 Project Overview

This project is part of the **50 Days Web Development Challenge** by **Synexus**.

On Day 12, I transformed a static responsive navigation bar into a fully interactive **mobile navigation menu** using **Vanilla JavaScript**. The project demonstrates UI state manipulation by dynamically showing and hiding the navigation menu with a hamburger button while maintaining accessibility and responsive design.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Google Fonts (Poppins)
