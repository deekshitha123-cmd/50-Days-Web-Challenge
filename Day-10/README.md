# 🌐 Synexus Community Platform

> Day 10 - Phase 1 Integration | 50 Days Web Development Challenge

## 📖 Overview

The Synexus Community Platform is a fully responsive static website developed using HTML5 and CSS3 as part of the **50 Days Web Development Challenge**.

This project integrates all the components built during Days 1–9 into a single professional website following modern frontend development practices.
