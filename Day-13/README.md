# 🚀 Day 13 – Client-Side Form Validation & Conditional Logic

## 📌 Project Overview

This project is part of the **50 Days Web Development Challenge by Synexus**.

On Day 13, the focus was on implementing **Client-Side Form Validation** using **Vanilla JavaScript**. The application validates user inputs before submission, preventing invalid data from being processed and improving the overall user experience.

---

## 🎯 Objectives

- Validate user input before form submission.
- Prevent page reload using `event.preventDefault()`.
- Display meaningful error messages.
- Highlight invalid input fields.
- Accept only valid data.
- Practice JavaScript conditional logic and DOM manipulation.

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

---

## ✨ Features

### Responsive Navigation
- Responsive navigation bar
- Mobile hamburger menu
- Navigation toggle using JavaScript
- Accessible navigation using `aria-expanded`

### Membership Form
- Full Name field
- Email field
- Submit button

### Form Validation
- Prevents empty Full Name.
- Prevents empty Email.
- Validates email using the `@` symbol.
- Displays inline error messages.
- Highlights invalid fields with a red border.
- Highlights valid fields with a green border.
- Clears the form after successful submission.
- Displays a success alert.

---

## 📸 Expected Output

### Invalid Name

- Red border appears.
- Error message:
  ```
  Full Name cannot be empty.
  ```

### Invalid Email

- Red border appears.
- Error message:
  ```
  Please enter a valid email address.
  ```

### Valid Submission

- Success alert appears.
- Console displays:
  ```
  Application Ready for Server
  ```
- Form resets automatically.
