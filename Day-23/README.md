# 📋 Day 23 - Kanban Board (HTML5 Drag & Drop API)

## 🚀 Project Overview

This project demonstrates how to build a Kanban Board using the native HTML5 Drag and Drop API without any external libraries.

Users can drag tasks between three workflow stages:

- 📝 To Do
- ⚡ In Progress
- ✅ Done

The project mimics the basic functionality of popular project management tools like Trello, Jira, and Asana.

## 📸 Preview

## 🧠 Workflow

1. Select a task.

2. Start dragging.

3. The task opacity changes.

4. Drop it into another column.

5. The task automatically moves.
