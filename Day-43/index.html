💡 Key Concepts

🏪

Centralized State

One store maintains the shared application state.

📢

Pub/Sub

Subscribers automatically receive state-change notifications.

⚡

Reactivity

UI updates automatically when the global state changes.

🧹

Unsubscribe

Listeners can be removed to prevent memory leaks.

🧩 The Core Idea 

globalStore.setState({
    cartCount: 5
});

Calling setState() updates the centralized state and automatically notifies every subscribed component.
